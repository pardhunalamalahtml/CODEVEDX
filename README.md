# CODEVEDX Frontend Development Projects

This repository contains my frontend development projects completed as part of the **CodeVedX Frontend Development Internship**.

## Projects

### 1. Task Manager

A simple and responsive Task Manager built with React.

#### Features

* Add tasks
* Edit tasks
* Delete tasks
* Mark tasks as completed
* All / Pending / Completed filters
* Dark / Light mode
* LocalStorage persistence
* Responsive design

#### Tech Stack

* HTML
* CSS
* JavaScript
* React
* Vite
* LocalStorage

---

### 2. Weather App

A simple weather application that allows users to search for the current weather of any city.

#### Features

* Search weather by city name
* Current temperature
* Weather condition
* Weather icon
* Feels-like temperature
* Humidity
* Wind speed
* Loading message
* Error handling
* Responsive design
* Press Enter to search

#### Tech Stack

* HTML
* CSS
* JavaScript
* React
* Vite
* OpenWeather API
