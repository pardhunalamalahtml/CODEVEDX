# CODEVEDX Task 1 - Task Manager
A simple Task Manager built with React for the CodeVedX Frontend Development internship.
## Features
- Day One
- Add tasks
- Edit tasks
- Delete tasks
- Day Two
- Mark tasks as completed
- All / Pending / Completed filters
- Dark / Light mode
- LocalStorage persistence
- Responsive design
## Tech Stack
- Day One
- HTML
- CSS
- JavaScript
- Day Two
- React
- LocalStorage
- Vite
