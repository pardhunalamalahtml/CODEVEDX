# CODEVEDX — Frontend Development Projects

Welcome to my frontend development project portfolio! This repository contains three projects built to practice and improve my skills in web development, JavaScript, React.js, API integration, and responsive user interface design.

## Projects

### 1. Task Manager App

A task management application that helps users organize and track their daily activities.

**Features**
- Add, edit, and delete tasks.
- Mark tasks as completed.
- Filter tasks by status.
- Dark and light theme switching.
- Save tasks using browser Local Storage.
- Responsive user interface.

**Technologies:** HTML5, CSS3, JavaScript, React.js, Vite, Local Storage.

### 2. Weather App

A weather application that retrieves current weather information for a searched city using the OpenWeather API.

**Features**
- Search weather by city name.
- Display current temperature and weather conditions.
- Show feels-like temperature, humidity, and wind speed.
- Handle API responses and invalid searches.
- Display weather information in a clean interface.
- Responsive layout for different screen sizes.

**Technologies:** HTML5, CSS3, JavaScript, React.js, Vite, OpenWeather API.

**API configuration:** Create a `.env` file in the project root and configure your API key:

```env
VITE_WEATHER_API_KEY=your_api_key_here
```

Never publish your actual API key in a public repository.

### 3. PardhuCart — E-Commerce Product Page

An e-commerce frontend application that provides a shopping interface for browsing products and managing a shopping cart.

**Features**
- Display products with prices and details.
- Add products to the cart.
- Update quantities and remove items.
- Calculate the cart total dynamically.
- Manage shared cart state using React Context API.
- Create a reusable, component-based interface.
- Responsive product layout.

**Technologies:** HTML5, CSS3, JavaScript, React.js, Vite, React Context API.

## Getting Started

### Prerequisites

- Node.js and npm
- Git
- A code editor such as Visual Studio Code
- An OpenWeather API key for the Weather App

### Run a Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/pardhunalamalahtml/CODEVEDX.git
   ```

2. Open the repository:

   ```bash
   cd CODEVEDX
   ```

3. Navigate into the folder of the project you want to run.

   For example:

   ```bash
   cd PardhuCart
   ```

   Replace `PardhuCart` with the actual folder name for the project you want to run.

4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown in the terminal.

Repeat these steps for the other projects, using their respective folders.
